```python
    返回: float（要最小化的值）
    """
    # 在这里实现你的目标函数
    # 例如：路径长度、成本、时间等
    cost = 0.0
    # ... 计算逻辑 ...
    return float(cost)

def constraint1(solution):
    """
```

## 四、三种算法的使用示例

### 4.1 遗传算法（GA）示例

**适用场景：** 排列问题（TSP、路径规划）、二进制决策（选址、背包）、连续优化、整数优化

#### 示例1：排列编码（TSP/路径问题）

```python
import numpy as np
from mcm_d_heuristics import OptimizationProblem, Penalty
from mcm_d_heuristics.ga import GeneticAlgorithm, GAConfig

# 定义TSP目标函数
N = 20  # 城市数量
dist_matrix = np.random.rand(N, N)  # 距离矩阵

def route_cost(route):
    """计算路径总长度"""
    route = np.asarray(route, dtype=int)
    cost = 0.0
    for i in range(len(route) - 1):
        cost += dist_matrix[route[i], route[i+1]]
    cost += dist_matrix[route[-1], route[0]]  # 回到起点
    return float(cost)

# 创建问题
problem = OptimizationProblem(
    objective=route_cost,
    decoder=None,
    constraints=[],
    penalty=Penalty(weight=1e9),
)

# 运行GA
ga = GeneticAlgorithm(
    problem,
    GAConfig(
        encoding="permutation",
        perm_size=N,          # 排列长度
        n_pop=100,
        max_gen=200,
        cx_rate=0.9,
        mut_rate=0.05,
        elitism_k=2,
        seed=42,
    )
)
best_route, best_cost = ga.run()
print(f"最优路径: {best_route}")
print(f"最优距离: {best_cost:.4f}")
```

### 4.2 粒子群优化（PSO）示例

**适用场景：** 连续优化问题，通过decoder可处理离散问题.PSO 处理离散 TSP 问题（Random Key 机制）效果通常远不如 GA.对于纯路径/排序问题，首选 GA/SA；PSO 仅用于连续变量（如功率、流量比例）或混合编码。

```python
import numpy as np
from mcm_d_heuristics import OptimizationProblem, Penalty
from mcm_d_heuristics.pso import ParticleSwarmOptimizer, PSOConfig
from mcm_d_heuristics.problem import decode_random_keys_to_permutation

# 示例1：连续优化
def objective_continuous(x):
    """连续目标函数"""
    x = np.asarray(x).reshape(-1)
    return float(np.sum(x ** 2))

problem_continuous = OptimizationProblem(
    objective=objective_continuous,
    decoder=None,
    lb=np.array([-10.0, -10.0, -10.0]),  # 下界
    ub=np.array([10.0, 10.0, 10.0]),     # 上界
)

pso = ParticleSwarmOptimizer(
    problem_continuous,
    PSOConfig(
        num_particles=40,      # 粒子数
        max_iter=200,          # 最大迭代次数
        topology="gbest",      # "gbest" 或 "lbest"
        adaptive=True,         # 自适应参数
        w_max=0.9,            # 惯性权重最大值
        w_min=0.4,            # 惯性权重最小值
        c1_max=2.5,           # 个体学习因子最大值
        c1_min=0.5,           # 个体学习因子最小值
        c2_min=0.5,           # 社会学习因子最小值
        c2_max=2.5,           # 社会学习因子最大值
        v_clamp_frac=0.2,     # 速度限制比例
        seed=7,
    )
)
best_sol, best_cost = pso.run()
print(f"最优解: {best_sol}, 最优成本: {best_cost:.4f}")

# 示例2：离散优化（通过Random-Keys解码）
def route_cost(route):
    """TSP路径成本"""
    # ... 实现路径成本计算 ...
    return cost

problem_discrete = OptimizationProblem(
    objective=route_cost,
```

### 4.3 模拟退火（SA）示例

**适用场景：** 排列问题、连续优化（通过不同邻域算子）

```python
import numpy as np
from mcm_d_heuristics import OptimizationProblem, Penalty
from mcm_d_heuristics.sa import SimulatedAnnealing, SAConfig
from mcm_d_heuristics.sa import op_swap, op_insert, op_reverse, op_gaussian

# 示例1：排列问题（TSP）
def init_route(rng):
    """初始化路径"""
    return rng.permutation(N)

sa = SimulatedAnnealing(
    problem,
    init_solution=init_route,
    neighbor_ops=[op_swap, op_insert, op_reverse],  # 多邻域算子
    config=SAConfig(
        T_start=50.0,          # 初始温度
        T_end=1e-3,            # 终止温度
        alpha=0.98,            # 降温系数
        iters_per_T=50,       # 每个温度的迭代次数
        seed=42,
    )
)
best_sol, best_cost = sa.run()

# 示例2：连续优化（高斯邻域）
def init_continuous(rng):
    """初始化连续解"""
    return rng.uniform(-10.0, 10.0, size=(5,))

sa_continuous = SimulatedAnnealing(
    problem,
    init_solution=init_continuous,
    neighbor_ops=[lambda s, rng: op_gaussian(s, rng, sigma=0.5)],  # 高斯变异
    config=SAConfig(T_start=10.0, T_end=1e-3, alpha=0.95, iters_per_T=30, seed=3)
)
best_sol, best_cost = sa_continuous.run()
```

## 五、常见问题排查

### 问题1：ImportError: attempted relative import with no known parent package

**错误信息：**
```
ImportError: attempted relative import with no known parent package
```

**原因：** 直接运行了 `ga.py`, `pso.py`, `sa.py` 等库文件

**解决方法：**
1. ❌ **不要运行：** `python mcm_d_heuristics/ga.py`
2. ✅ **应该运行：** 
   - 使用模块运行：`python -m mcm_d_heuristics.examples.test_x2`
   - 或创建自己的脚本文件，在其中导入使用

**错误信息：**
```
ModuleNotFoundError: No module named 'mcm_d_heuristics'
```

**原因：** Python找不到包路径

**解决方法：**

---

### 问题3：参数配置错误

**常见错误：**
- `permutation` 编码时忘记设置 `perm_size`
- `real`/`integer` 编码时忘记设置 `lb`/`ub`
- PSO 使用时忘记设置 `lb`/`ub`

**解决方法：**
- 检查 `GAConfig` 或 `PSOConfig` 的参数是否与 `encoding` 匹配
- 参考本文档的示例代码

---

### 问题4：约束不满足

**现象：** 算法找到的解违反了约束条件

**解决方法：**
1. 检查约束函数的返回值是否正确（应返回 violation >= 0）
2. 增大 `Penalty` 的 `weight` 值（如 `1e10`）
3. 在 `objective` 函数中直接处理约束（硬约束）

## 六、D题快速套用清单

### 6.1 问题分析步骤

1. **识别问题类型**
   - [ ] 排列问题（路径、顺序）→ 使用 GA(permutation) 或 SA
   - [ ] 0/1决策（选址、选择）→ 使用 GA(binary)
   - [ ] 连续参数优化 → 使用 GA(real) 或 PSO
   - [ ] 整数决策（数量、分配）→ 使用 GA(integer)

2. **定义目标函数**
   - [ ] 明确要最小化/最大化的量
   - [ ] 将问题转化为数学表达式
   - [ ] 实现为Python函数

3. **识别约束条件**
   - [ ] 列出所有约束
   - [ ] 实现约束检查函数
   - [ ] 确定约束处理方式（惩罚函数 or 硬约束）

4. **选择算法**
   - [ ] 根据问题类型选择GA/PSO/SA
   - [ ] 确定编码方式
   - [ ] 设置初始参数

### 6.3 参数调优建议

#### GA参数调优

| 参数 | 建议范围 | 说明 |
|------|---------|------|
| `n_pop` | 50-200 | 问题规模大时增大 |
| `max_gen` | 100-500 | 根据收敛情况调整 |
| `cx_rate` | 0.7-0.95 | 交叉概率，通常0.9 |
| `mut_rate` | 0.01-0.1 | 变异概率，通常0.05 |
| `elitism_k` | 1-5 | 精英保留数量 |

#### PSO参数调优

| 参数 | 建议范围 | 说明 |
|------|---------|------|
| `num_particles` | 30-100 | 粒子数量 |
| `max_iter` | 100-500 | 迭代次数 |
| `topology` | "gbest"/"lbest" | gbest收敛快，lbest多样性好 |
| `adaptive` | True/False | 建议True（自适应） |

#### SA参数调优

| 参数 | 建议范围 | 说明 |
|------|---------|------|
| `T_start` | 10-100 | 初始温度，根据目标函数值范围调整 |
| `T_end` | 1e-5到1e-2 | 终止温度 |
| `alpha` | 0.95-0.99 | 降温系数，越大降温越慢 |
| `iters_per_T` | 20-100 | 每个温度的迭代次数 |
