## 1) 入库文件清单（逐文件说明 + 验收标准）

### A. `configs/constants.py`  （P0：单一真理源，必须入库）

**目的**：冻结题面参数 + 你的情景参数（$K,r,q$）+ 成本符号/区间，禁止魔法数字散落。

**建议内容（接口约束）**

```python
from dataclasses import dataclass
from typing import Tuple, List

@dataclass(frozen=True)
class Problem:
    START_YEAR: int = 2050
    TOTAL_MASS_TONS: float = 100_000_000  # metric tons

@dataclass(frozen=True)
class Elevator:
    NUM_HARBOURS: int = 3
    CAPACITY_PER_HARBOUR_TPY: float = 179_000  # tons/year

@dataclass(frozen=True)
class Rocket:
    MAX_SITES: int = 10
    PAYLOAD_RANGE_TON: Tuple[float, float] = (100.0, 150.0)  # tons/launch
    DAILY_RATE_SET: Tuple[int, int] = (1, 2)  # launches/day/site (Q1只算1与2)

@dataclass(frozen=True)
class Cost:
    # 只放“符号/区间/占位”，不在Q1把它写死成事实
    # 传统 Earth→Moon 单次发射成本区间（你后续再填数或引用文献）
    C_LAUNCH_RANGE_USD: Tuple[float, float] = (float("nan"), float("nan"))
    # Apex→Moon 单次发射成本折扣（相对传统火箭），可用区间表达
    BETA_APEX_RANGE: Tuple[float, float] = (0.1, 0.5)
    # 电梯每吨运营成本（电力+维护），先占位
    C_ELEVATOR_PER_TON_USD: float = float("nan")
```

**验收标准**

* 仓库中**所有** $M,H,C_p,q,K,r$ 只从这里读取。
* 论文“参数表”从这里复制即可（写作记录同步）。

### B. `src/q1/capacity.py` （Q1核心：吞吐/发射次数/工期）

**目的**：把你要的“像电梯一样定量”写成纯函数（可单测）。

**必须提供的函数签名**

```python
def elevator_total_capacity_tpy(num_harbours: int, cap_per_harbour_tpy: float) -> float: ...

def rocket_annual_capacity_tpy(K: int, r_daily: int, payload_ton: float) -> float: ...

def rocket_launches_required(total_mass_ton: float, payload_ton: float) -> int: ...

def completion_time_years(total_mass_ton: float, annual_capacity_tpy: float) -> float: ...
```

**验收标准**

* `rocket_launches_required(1e8,150)=666667`；`rocket_launches_required(1e8,100)=1000000`（向上取整）。
* `completion_time_years(M, 3*179000)` 输出约 186.22 年（允许浮点误差）。

### C. `src/q1/cost.py`（Q1成本表达式：先符号化/区间化）

**目的**：Q1 先把成本写成**可代入的表达式**或“区间结果”，避免硬编码争议数字。

**建议函数签名**

```python
from typing import Dict, Tuple

def cost_scenario_A(total_mass_ton: float,
                    c_elevator_per_ton: float,
                    c_apex_launch: float,
                    q_apex_ton: float) -> float: ...

def cost_scenario_B(n_launches: int, c_launch: float) -> float: ...

def cost_scenario_C(alpha: float,
                    total_mass_ton: float,
                    c_elevator_per_ton: float,
                    c_apex_per_ton: float,
                    c_rocket_per_ton: float) -> float: ...
```

**验收标准**

* 在 Q1 阶段允许 `c_*` 为 `nan` 或区间，代码不崩：若缺成本数据，就只输出“公式/符号”，同时输出工期硬数。

### E. `src/q1/feasibility.py`（你说的“不等式测试件”，必须入库）

**目的**：把混合的产能不等式变成“可验证工具”，用于 sanity check 和写作中的必要条件。

**函数签名（必须）**

```python
def feasible_within_T(total_mass_ton: float,
                      T_years: float,
                      C_elevator_tpy: float,
                      C_rocket_tpy: float) -> bool: ...

def lower_bound_time_years(total_mass_ton: float,
                           C_elevator_tpy: float,
                           C_rocket_tpy: float) -> float: ...

def alpha_star(C_elevator_tpy: float, C_rocket_tpy: float) -> float: ...
```

**验收标准**

* `lower_bound_time_years(M, C_E, C_R)` 等于 $M/(C_E+C_R)$。
* `alpha_star` 等于 $C_E/(C_E+C_R)$，落在 $[0,1]$。

### F. `src/q1/robustness_interval.py`（Q1鲁棒：区间敏感性，不做随机仿真）

**目的**：你提到“写进论文但别装成真实风险”，那就只做 **interval sensitivity**：$q$、$r$、$K$、电梯运力扰动 $\delta$。

**函数签名**

```python
from typing import Dict, Tuple

def interval_time_A(total_mass_ton: float, C_elevator_tpy: float, delta: float) -> Tuple[float, float]: ...

def interval_time_B(total_mass_ton: float, K_range: Tuple[int, int],
                    r_set: Tuple[int, ...], q_range: Tuple[float, float]) -> Dict[str, Tuple[float, float]]: ...

def interval_time_C_lower_bound(total_mass_ton: float, C_elevator_tpy: float,
                                K_range: Tuple[int, int], r_set: Tuple[int, ...], q_range: Tuple[float, float]) -> Dict[str, Tuple[float, float]]: ...
```

**验收标准**

* 输出能直接写进论文的硬范围（best/worst），并且能对应到“哪个参数组合导致”。
