# Q2 鲁棒性分析流程图

本流程图描述了针对 **问题 2 (不完美状态下的运输系统)** 的建模求解逻辑。采用 **“闭式期望分析 (Analytical)”** 与 **“蒙特卡洛仿真 (Simulation)”** 相结合的方法，既保证理论深度，又量化尾部风险。

```mermaid
graph TD
    %% 定义样式
    classDef input fill:#f9f,stroke:#333,stroke-width:2px;
    classDef process fill:#e1f5fe,stroke:#0277bd,stroke-width:2px;
    classDef output fill:#e8f5e9,stroke:#2e7d32,stroke-width:2px;
    classDef decision fill:#fff9c4,stroke:#fbc02d,stroke-width:2px;

    %% 输入部分
    subgraph Input_Phase [输入参数定义 (Failure-to-Parameter Mapping)]
        direction TB
        I1[基础参数<br/>M=100Mt, C_E, C_R]:::input
        I2[不完美参数集合]:::input
        I2 --> I2a[电梯失效参数<br/>λ_E: 故障率<br/>μ_E: 修复率<br/>a_E: 长期可用率]
        I2 --> I2b[火箭失效参数<br/>p_R: 单次发射失败率<br/>τ_reset: 事故清场时间]
        I2 --> I2c[环境参数<br/>a_B: 基地气象/窗口可用率]
    end

    %% 阶段一：解析模型
    subgraph Analytical_Phase [阶段一: 闭式期望分析 (Mean-Value Analysis)]
        direction TB
        A1[计算有效吞吐量 (Effective Throughput)]:::process
        I2a --> A1
        I2b --> A1
        A1 --> A2a["电梯期望吞吐: <br/>C̃_E = a_E * C_E"]
        A1 --> A2b["火箭期望吞吐: <br/>C̃_R = a_B * s_R * C_R_eff"]

        A2a & A2b --> A3[计算最优混合比例漂移 α*]:::decision
        A3 -->|"α* = C̃_E / (C̃_E + C̃_R)"| A4[工期期望 E(T)]

        A4 --> A5[必要条件检查 (Reachability)]:::process
        A5 --> O1[输出: 理论可行域 & α* 迁移曲线]:::output
    end

    %% 阶段二：仿真模型
    subgraph Simulation_Phase [阶段二: 蒙特卡洛仿真 (Variance & Tail Risk)]
        direction TB
        S1[初始化 N 次仿真实验]:::process
        I2a --> S2a[电梯生成器: <br/>CTMC (On-Off 状态切换)<br/>模拟连续停机 (Burst Downtime)]
        I2b --> S2b[火箭生成器: <br/>Bernoulli 试验 + <br/>故障触发 Pad 冻结 (τ_reset)]

        S2a & S2b --> S3{策略选择}
        S3 -->|Static| S4a[固定比例 α* 策略]
        S3 -->|Dynamic| S4b[动态备份策略<br/>(电梯停机时火箭加速)]

        S4a & S4b --> S5[统计分布分析]:::process
        S5 --> O2[输出: 工期分布直方图]:::output
        S5 --> O3[输出: 风险指标 VaR (95%) <br/> & 按期完成概率]:::output
    end

    %% 综合分析
    subgraph Conclusion [综合结论]
        C1[鲁棒性评级]:::decision
        O1 --> C1
        O2 --> C1
        O3 --> C1
        C1 --> Final[论文结论: <br/>1. α* 随可靠性漂移规律<br/>2. 极端风险下的缓冲时间建议]:::output
    end

    Input_Phase --> Analytical_Phase
    Input_Phase --> Simulation_Phase
```

## 核心逻辑说明

1.  **输入映射 (Input Mapping)**: 将题面描述的定性风险（如 "tether swaying", "rockets fail"）转化为可计算的数学参数 ($a_E, p_R, \tau_{reset}$)。
2.  **解析路径 (Analytical)**: 关注**均值**。回答“如果设备不可靠，我们平均需要多长时间？最优策略 $\alpha$ 应该偏向哪一方？”
3.  **仿真路径 (Simulation)**: 关注**方差与风险**。解析解无法体现“电梯一坏就是一个月”这种集中风险带来的工期波动，必须通过 Monte Carlo 模拟 On-Off 过程来计算 95% 置信度下的最坏工期 (VaR)。
