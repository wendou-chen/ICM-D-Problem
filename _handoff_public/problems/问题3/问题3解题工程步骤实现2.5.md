6.7.2 建模公式（脚本与论文共享）
需求替换是唯一变化：
$$\begin{equation}\nd_{\text{day}}^{\text{ship}} = \max\{0,\; d_{\text{day}} - u\}\n\end{equation}$$
库存动力学（保持不变，只是换了消耗项）：
$$W_{t+1} = W_t + x_{E,t}^{\text{actual}} + x_{R,t}^{\text{actual}} - d_{\text{day}}^{\text{ship}}$$
断供概率：
$$P_{\text{stockout}}(\gamma) = \frac{1}{N} \sum_{i=1}^N \mathbf{1}{\{\min{t \in [1,365]} W_t^{(i)} < 0\}}$$
预算风险（VaR）：
$$\mathrm{VaR}_{0.95}(Cost|\gamma) = \inf \left\{ c : \Pr(Cost \le c) \ge 0.95 \right\}$$
