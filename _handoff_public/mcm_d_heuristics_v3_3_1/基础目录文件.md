## 2）封装算法库汇总
| 文件名 | 核心算法/类 | 功能说明 |
| --- | --- | --- |
| __init__.py | 入口导出 | 汇总导出 OptimizationProblem/Penalty、GA/PSO/SA、Path GA、Flow、Schedule 等 |
| README.md | 使用说明 | 目录、安装方式、Problem-Algorithm 解耦示例 |
| 运行步骤.md | 运行指南 | 示例运行命令、环境依赖、路径配置、常见问题与模板 |

| problem.py | OptimizationProblem, Penalty, ParetoArchive 及解码/修复接口 | 定义目标/约束/惩罚/边界与多目标标量化；常用解码器（随机键→排列、sigmoid→二进制、四舍五入→整数） |
| ga.py | GeneticAlgorithm, GAConfig, PathGeneticAlgorithm/PathGAConfig | 通用 GA（排列/二进制/实数/整数）、精英保留、交叉/变异、停滞触发自定义变异；可变长路径 GA |
| pso.py | ParticleSwarmOptimizer, PSOConfig | 通用 PSO（gbest/lbest、自适应惯性与加速、速度截断、反射边界），需要 lb/ub |
| sa.py | SimulatedAnnealing, SAConfig, 邻域算子(op_swap/op_insert/op_reverse/op_gaussian) | 通用 SA，支持多邻域随机选择，适配排列或连续 |
| flow.py | Commodity, PathFlowModel, build_path_flow_model, make_min_cost_flow_problem, make_min_max_congestion_problem, op_congestion_shift | 路径流建模与修复，最小成本流/最小最大拥塞问题构造，领域拥塞转移算子 |
| graph_io.py | GraphDistance, k_shortest_paths, repair_path, biased_random_walk_path 等 | 图读写/最短路矩阵、k最短简单路、路径修复与偏置随机游走播种 |
| schedule.py | Task, SSGSDecoder, ScheduleResult, makespan_objective | 调度优先级解码（SSGS），生成可行甘特，返回完工期目标 |
| viz.py | Visualizer + 绘图函数 | 收敛曲线、网络热力/高亮、甘特图、路径轨迹等可视化工具 |
| network_algo.py | NetworkSolver | 网络中心性、最短路、MST、鲁棒性指标封装 |
| opt_algo.py | OptimizationSolver | 基于 SciPy 的 LP/MIP 求解封装，含灵敏度分析提示 |
| mcm_d_heuristics_v3_3_1.rar | 归档文件 | 原始压缩包（未解压内容同目录版本） |
