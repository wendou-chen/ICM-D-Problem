在现有项目基础上实现 Q2（non-perfect working order）。保持 Q1 不变，新增 src/q2 与 scripts/run_q2.py。

A. configs/constants.py
保留原 Problem/Elevator/Rocket/Cost 不动。
新增 dataclass ReliabilityPreset，包括：
- A_E (float)  # elevator availability, dimensionless
- MTTR_E_DAYS (float)
- P_R (float)  # rocket failure prob per attempt
- TAU_RESET_DAYS (int)
- A_B (float)  # base availability
并给出三个 preset：MILD/MODERATE/SEVERE（写在字典或三个实例中）。
同时提供函数把 (A_E, MTTR) 转为 (lambda, mu):
mu = 1/MTTR, lambda = mu*(1-A_E)/A_E

B. src/q2/analytics.py
实现闭式：
- elevator_effective_capacity(C_E, A_E) -> C_E_tilde
- rocket_f_eff(r, p_R, tau_reset) using:
  s = 1 - p_R
  E_S = sum_{i=1..r} s^i
  E_L = 1 + tau_reset*(1 - s^r)
  f_eff = E_S / E_L
- rocket_effective_capacity(K, r, q, A_B, p_R, tau_reset) -> C_R_tilde (tons/year)
- alpha_star(C_E_tilde, C_R_tilde)
- expected_time_A/B/C
- feasible(T_target_years): (C_E_tilde + C_R_tilde) >= M/T_target

C. src/q2/simulator.py（日步长）
状态：
- elevator_down_days (int)
- pad_down_days[K] (int)
每日更新：
- 电梯：按 (lambda, mu) 或几何过程模拟 burst downtime（down_remaining_days 显式）
- 火箭：每基地若可用则顺序尝试 <= r 次；失败则 break 并 set pad_down_days[i]=TAU_RESET_DAYS
策略 policy：
- fixed_alpha_star: 尽量维持累计份额 alpha*
- dynamic_backup: 若电梯 down，则火箭使用 r_max=2，否则用 r_base=1（或按输入）
输出：完成时间 years

D. src/q2/metrics.py
输出 mean/std/VaR95/CVaR95/P_on_time

E. src/q2/plots.py
输出三图到 outputs/q2/figs：
- alpha_drift.png（alpha* vs A_E 或 p_R）
- boxplot_time.png（A/B/C × policy 的完工时间箱线图）
- feasibility_region.png（用 feasible() 画相图）

F. scripts/run_q2.py
一键运行：
1) analytic 计算表 -> outputs/q2/q2_analytic.csv
2) Monte Carlo (默认 300 次) -> outputs/q2/q2_mc_summary.csv
3) 生成 figs

验收：
- run_q2.py 可运行
- 输出 csv/figs 齐全
- 单调性正确（A_E 降低 => mean_time 增大；p_R 增大 => mean_time 增大）
