## 2.1 CO₂（运营期：火箭直排 + 电梯用电间接排）

### 数学式

[
E_{\mathrm{CO2}} = \underbrace{\Big(\sum_t N_{\text{att},t}\Big),e_{\mathrm{CO2}}^{R}}*{\text{rocket}}
;+;
\underbrace{\Big(\sum_t m^{E}*t\Big)\ \epsilon_E\ g*{\text{grid}}\ (1-\chi)}*{\text{elevator electricity}}
]

* $N_{\text{att},t}\equiv n_\text{plan}$（每日尝试次数）
* $m^E_t$：电梯当日交付吨数（**用你引擎里“实际交付”那个变量**，而不是 $\alpha M$ 静态替代，保证与失效工况耦合）
* $\epsilon_E$：电梯单位能耗（kWh/ton）
* $g_{\text{grid}}$：电网碳强度（kgCO₂/kWh）
* $\chi$：去碳化比例（0=全用电网，1=全绿电/专供能源）

题面“电梯无大气污染”允许你把“电梯直接排放=0”，但**间接排放取决于供电碳强度**，这与你的 $\chi$ 旋钮完全一致。

### 代码变量名（建议）

* `attempts_total` = $\sum_t N_{\text{att},t}$
* `mass_elevator_total_ton` = $\sum_t m^{E}_t$
* `e_CO2_per_attempt_ton` = $e_{\mathrm{CO2}}^{R}$（**单位：ton CO2 / attempt**）
* `epsilon_E_kwh_per_ton` = $\epsilon_E$
* `g_grid_kgco2_per_kwh` = $g_{\text{grid}}$
* `chi_green` = $\chi$

实现时统一单位：

* `E_CO2_rocket_ton = attempts_total * e_CO2_per_attempt_ton`
* `E_CO2_elev_ton = mass_elevator_total_ton * epsilon_E_kwh_per_ton * g_grid_kgco2_per_kwh*(1-chi_green)/1000`

## 2.2 平流层黑碳：漏桶库存（核心“物理叙事”）

上传 docx 给了“平流层驻留多年、累积成层、气候效率可达 500–1500 倍”的叙事来源与参数位。你不把它硬转成 CO₂e，而是用库存动力学，**审稿抗性更强**。

### 数学式（按日步长）

[
u_t = N_{\text{att},t}\ e_{\mathrm{BC}}^{R},\qquad
S_{t+1} = (1-\delta)S_t + u_t,\ \delta = \frac{1}{\tau_{\text{days}}}
]
[
E_{\mathrm{BC}}=\sum_t u_t,\qquad S_{\max}=\max_t S_t
]

* $\tau$（years）可取 2/4/6 年做敏感性（docx 明确提到 residence time 的角色）

### 代码变量名

* `e_BC_per_attempt_ton`
* `tau_bc_years`
* `delta_bc = 1.0 / (tau_bc_years * 365.0)`
* `S_bc_stock_ton`（状态）
* `S_bc_max_ton`（统计）

日循环更新（**只加这一行，不改调度**）：

* `u_bc = n_plan * e_BC_per_attempt_ton`
* `S_bc = (1-delta_bc)*S_bc + u_bc`
* `S_bc_max = max(S_bc_max, S_bc)`

> 注意：如果你的火箭在 Scenario A（电梯链路）只负责 Apex→Moon，那么它不属于大气注入；Q4 环境模块只记录 **地面发射的** `n_plan_ground`。题面“电梯系统无大气污染”也支持这个边界划分。

## 2.3 臭氧风险代理：年度发射预算惩罚/约束（可行域判定）

题面没有要求你定量臭氧化学，但你要给“监管式可行域”。docx 也强调了“臭氧层破坏/平流层加热”的风险机制，可作为定性支撑。

### 软惩罚

[
E_{\mathrm{O3}}=\sum_{y}\max\big(0,\ N_{\text{att},y}-N^{\text{safe}}_{\text{year}}\big)
]

### 硬约束（用于 Feasible/Infesible 标色）

[
N_{\text{att},y}\le N^{\max}_{\text{year}},\ \forall y
]

### 代码变量名

* `attempts_by_year: dict[int,float]`
* `N_safe_year`
* `N_max_year`
* `E_O3_penalty = sum(max(0, attempts_by_year[y]-N_safe_year) for y in years)`
* `feasible_o3 = all(attempts_by_year[y] <= N_max_year for y in years)`

年索引映射：`year = t // 365`（与你 Q3 日步长一致）。

## 3.2 `EnvLedger` 接口（你直接照着写）

### 核心数据结构

```python
@dataclass
class EnvConfig:
    # rocket (per attempt, already includes refuel multiplier if you choose this route)
    e_CO2_per_attempt_ton: float
    e_BC_per_attempt_ton: float

    # BC leaky bucket
    tau_bc_years: float

    # elevator electricity
    epsilon_E_kwh_per_ton: float
    g_grid_kgco2_per_kwh: float
    chi_green: float

    # elevator LCA build
    m_tether_total_ton: float
    e_graphene_MJ_per_kg: float
    g_mfg_kgco2_per_MJ: float

    # ozone proxy
    N_safe_year: float
    N_max_year: float

    # local
    w_site: dict[str, float] | None = None
```

### 日更新（与 Q3 日循环同位置）

```python
class EnvLedger:
    def __init__(self, cfg: EnvConfig):
        self.cfg = cfg
        self.attempts_total = 0.0
        self.attempts_by_year = defaultdict(float)
        self.attempts_by_site = defaultdict(float)

        self.mass_elevator_total_ton = 0.0

        self.S_bc = 0.0
        self.S_bc_max = 0.0
        self.E_BC = 0.0

    def step_day(self, t: int, n_plan: float, m_elev_day_ton: float,
                 site_attempts: dict[str, float] | None = None):
        y = t // 365

        # 1) attempts counters (coupled to Q3: emissions should follow n_plan):contentReference[oaicite:26]{index=26}
        self.attempts_total += n_plan
        self.attempts_by_year[y] += n_plan

        if site_attempts is not None:
            for j, v in site_attempts.items():
                self.attempts_by_site[j] += v

        # 2) elevator throughput (for indirect electricity CO2)
        self.mass_elevator_total_ton += m_elev_day_ton

        # 3) BC leaky bucket
        delta = 1.0 / (self.cfg.tau_bc_years * 365.0)
        u_bc = n_plan * self.cfg.e_BC_per_attempt_ton
        self.E_BC += u_bc
        self.S_bc = (1.0 - delta) * self.S_bc + u_bc
        self.S_bc_max = max(self.S_bc_max, self.S_bc)

    def finalize(self):
        # CO2 rocket
        E_CO2_rocket_ton = self.attempts_total * self.cfg.e_CO2_per_attempt_ton

        # CO2 elevator electricity
        E_CO2_elev_ton = (
            self.mass_elevator_total_ton
            * self.cfg.epsilon_E_kwh_per_ton
            * self.cfg.g_grid_kgco2_per_kwh
            * (1.0 - self.cfg.chi_green)
            / 1000.0
        )

        # O3 penalty + feasibility
        E_O3 = sum(max(0.0, v - self.cfg.N_safe_year) for v in self.attempts_by_year.values())
        feasible_o3 = all(v <= self.cfg.N_max_year for v in self.attempts_by_year.values())

        # LCA build (ton CO2)
        E_LCA_build_ton = (
            self.cfg.m_tether_total_ton * 1000.0
            * self.cfg.e_graphene_MJ_per_kg
            * self.cfg.g_mfg_kgco2_per_MJ
            / 1000.0
        )

        # local
        if self.cfg.w_site and len(self.attempts_by_site) > 0:
            E_loc = sum(self.cfg.w_site.get(j, 1.0) * v for j, v in self.attempts_by_site.items())
        else:
            E_loc = 0.0

        return dict(
            E_CO2_ton=E_CO2_rocket_ton + E_CO2_elev_ton,
            E_CO2_rocket_ton=E_CO2_rocket_ton,
            E_CO2_elev_ton=E_CO2_elev_ton,
            E_BC_ton=self.E_BC,
            S_max_ton=self.S_bc_max,
            E_O3=E_O3,
            feasible_o3=feasible_o3,
            E_LCA_ton=E_LCA_build_ton,
            E_loc=E_loc,
        )
```

[
\mathrm{EDI}(\pi)=\sum_{m\in\mathcal{M}}\omega_m\frac{E_m(\pi)}{E_m^{\text{ref}}}

代码变量：

* `EDI = sum(w[m] * env[m] / ref[m] for m in metrics)`

## 4.2 ε-constraint（最审稿友好，直接开扫）

[
\min\ \mathrm{EDI}(\pi)\quad
\text{s.t.}\quad T(\pi)\le \bar T,\ P_{\text{on-time}}(\pi)\ge 0.95,\ Z(\pi)\le \bar Z
]
并加可行域：
[
N_{\text{att},y}\le N^{\max}*{\text{year}},\quad S*{\max}\le S^{\max}
