## 融合优点后的“最终整合版 Q4 建模方案”（可直接写入论文）

下面是一份修正后的标准版结构，**完全兼容 Q1–Q3 引擎**，并补齐上述缺口。

# 1. 问题抽象与符号定义 (Abstraction & Notation)

## 1.1 集合与索引

* 发射场 $j\in\mathcal{J}$，$|\mathcal{J}|\le 10$
* 天索引 $t=0,1,\dots,T_d-1$（与 Q3 日步长一致）
* 年索引 $y\in\mathcal{Y}$，由映射 $y=y(t)$ 给出

## 1.2 决策变量

[
\pi=(\alpha,;K,;r,;\chi)
]

* $\alpha\in[0,1]$：电梯承担质量比例
* $K\in{1,\dots,10}$：启用火箭基地数
* $r$：火箭日尝试频次/调度强度（由你 Q2/Q3 policy 决定）
* $\chi\in[0,1]$：电梯用电去碳化比例（新变量）

## 1.3 仿真派生量（只加计数器）

* 日尝试次数：$N_{\text{att},t}$（你代码里就是每日 `n_plan`）
* 年尝试次数：$N_{\text{att},y}=\sum_{t\in y} N_{\text{att},t}$
* 基地尝试次数：$N_{\text{att},j}=\sum_t N_{\text{att},t,j}$（若你有基地分配）

# 2. 环境指标体系 (Vector Metrics)

定义环境向量：
[
\mathbf{E}(\pi)=\big(E_{\mathrm{CO2}},;E_{\mathrm{BC}},;S_{\max},;E_{\mathrm{O3}},;E_{\mathrm{LCA}},;E_{\mathrm{loc}}\big)
]

## 2.1 CO₂（运营期）

[
E_{\mathrm{CO2}}(\pi)=N_{\text{att}},e_{\mathrm{CO2}}^{R}
;+;
(\alpha M),\epsilon_E,g_{\text{grid}},(1-\chi)
]

* $N_{\text{att}}=\sum_t N_{\text{att},t}$
* $e_{\mathrm{CO2}}^R$：每次尝试 CO₂（情景参数：low/base/high）
* $\epsilon_E$：电梯提升能耗（kWh/ton，区间化）
* $g_{\text{grid}}$：电网碳强度（kgCO₂/kWh，区间化）

## 2.2 平流层黑碳：漏桶库存（核心机理）

[
u_t = N_{\text{att},t},e_{\mathrm{BC}}^{R}
]
[
S_{t+1}=(1-\delta)S_t+u_t,\qquad \delta=\frac{1}{\tau}
]
[
E_{\mathrm{BC}}=\sum_t u_t,\qquad S_{\max}=\max_t S_t
]

* $e_{\mathrm{BC}}^{R}$ 与 $\tau$ 都做敏感性（低/中/高），用来吸收“倍数争议”。

## 2.3 臭氧风险代理：年度预算惩罚/约束（二选一或同时用）

软惩罚：
[
E_{\mathrm{O3}}=\sum_{y\in\mathcal{Y}}\max\big(0,,N_{\text{att},y}-N^{\text{safe}}*{\text{year}}\big)
]
硬约束（可行域定义）：
[
N*{\text{att},y}\le N^{\max}_{\text{year}},\quad \forall y
]

## 2.4 电梯 LCA：建造碳债（主文保留这一个就够）

[
E_{\mathrm{LCA}}=E_{\text{build}}=m_{\text{tether}};e_{\text{graphene}}
]

* 注意：运营用电碳已计入 $E_{\mathrm{CO2}}$，避免重复记账。
* 火箭制造 LCA 可作为扩展项开关（附录即可）。

## 2.5 局地环境影响（把 10 个基地信息用起来）

[
E_{\mathrm{loc}}=\sum_{j\in\mathcal{J}} w_j,N_{\text{att},j}
]

* $w_j$ 为情景权重（人口密集/生态敏感取高；偏远取低），不需要精确数据也能自洽。

# 3. 模型调整：把环境并入决策（题面核心）

给三种并行写法（你原稿思路正确，但这里补齐数学闭合）：

## 3.1 三目标 Pareto

[
\min\ \big(Z(\pi),,T(\pi),,\mathrm{EDI}(\pi)\big)
]
其中 EDI 只做展示用归一化：
[
\mathrm{EDI}(\pi)=\sum_{m\in\mathcal{M}}\omega_m\frac{E_m(\pi)}{E_m^{\text{ref}}}
]
$\mathcal{M}$ 可取 ${\mathrm{CO2},,S_{\max},,E_{\mathrm{O3}},,E_{\mathrm{LCA}},,E_{\mathrm{loc}}}$。

## 3.2 $\varepsilon$-constraint（最审稿友好）

[
\min\ \mathrm{EDI}(\pi)\quad\text{s.t.}\quad T(\pi)\le \bar T,;;P_{\text{on-time}}(\pi)\ge 0.95,;;Z(\pi)\le \bar Z
]
并可加入硬约束：
[
S_{\max}(\pi)\le S^{\max},\quad N_{\text{att},y}\le N^{\max}_{\text{year}}
]

## 3.3 环境尾部风险（把 Q3 的 VaR/CVaR 迁移过来）

对 Monte Carlo 输出的 $S_{\max}^{(i)}$ 或 $\mathrm{EDI}^{(i)}$，做：
[
\min\ \mathrm{CVaR}*{0.95}(S*{\max})\quad\text{或}\quad \min\ \mathrm{CVaR}_{0.95}(\mathrm{EDI})
]
这会把“burst 触发应急火箭导致污染尖峰”的机制写得非常漂亮。

# 4. 工程落地 (最小侵入)

你原来三行计数器是对的，这里补一个“年聚合”和“基地聚合”的落地说明：

* 日循环（与你 Q2/Q3 现有循环同位置）：

  * `attempts_total += n_plan`
  * `attempts_by_year[y(t)] += n_plan`
  * `S = (1-delta)*S + n_plan * e_BC_per_attempt`
  * （可选）`attempts_by_site[j] += n_plan_j`
* 仿真结束：

  * 输出 $E_{\mathrm{CO2}}, E_{\mathrm{BC}}, S_{\max}, E_{\mathrm{O3}}, E_{\mathrm{LCA}}, E_{\mathrm{loc}}$
  * 统计 $\mathrm{VaR}*{0.95}$ / $\mathrm{CVaR}*{0.95}$

> 关于 refueling multiplier：统一用一个倍率参数 $\rho$，让“有效上行 1 次所需 attempts 数”由调度逻辑生成，即 $N_{\text{att}} \leftarrow \rho\times(\text{mission launches})$，不要同时再放大 $e^R$，避免重复放大。

## 结论句的“升级版”（更像论文 + 更不容易被挑刺）

> 我们将火箭环境影响建模为“按尝试次数计的平流层黑碳注入—多年驻留库存（漏桶模型）”，并对年度发射次数施加预算约束，从而把环境风险从定性比较提升为可行域判定。在该框架下，最优策略倾向于提高电梯承担比例 $\alpha$，并通过提升电梯供电去碳化水平 $\chi$ 降低运营期排放，同时保留火箭作为中断情景下的应急与尖峰能力，使成本—工期—环境三目标达到 Pareto 最优，并显著降低环境尾部风险（例如 $\mathrm{CVaR}*{0.95}(S*{\max})$）。
