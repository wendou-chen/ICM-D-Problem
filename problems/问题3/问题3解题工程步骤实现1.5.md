## 1) 最终结论：Step4 **必须画图**，但只做“最低两张必画 + 一张可选统计图”

你 Step4 的成本公式与变量是：

* 电梯成本分解（脚本已写死）：
  [
  C_E = X_E\cdot c_E + X_E\cdot c_{apex}
  ]
  对应：`cost_elevator_lift = avg_xE * c_E_per_ton`，`cost_elevator_apex = avg_xE * apex_cost_per_ton`

* 火箭成本（按成功率折算尝试次数）：
  [
  C_R = \frac{X_R/q}{s_R}\cdot C_L,\quad s_R=1-P_R
  ]
  对应：`s_R = 1 - preset.P_R`，`num_attempts = (avg_xR/q_payload)/s_R`，`total_cost_rocket = num_attempts * C_L_launch`

* 总成本：`total_annual_cost = total_cost_elevator + total_cost_rocket`

基于这些，推荐 Step4 输出：

### 必画图 1：成本分解堆叠柱（Cost Breakdown）

**目的**：把 `Lift Ops / Apex Transfer / Rocket` 三块堆叠出来，回答“钱花在哪”。
**输入变量名（已有）**：`cost_elevator_lift, cost_elevator_apex, total_cost_rocket`

输出文件建议：

* `outputs/q3/step4/fig_step4_cost_breakdown.png`
* 同步导出 `pdf`（论文插图更稳）

---

### 必画图 2：倒挂双轴图（Mass Share vs Cost Share）

**目的**：一眼讲清你的“80/20 vs 35/65”核心发现（比 pie 强）。
**输入变量名（已有）**：

* 运量占比：`avg_xE, avg_xR`
* 成本占比：`total_cost_elevator, total_cost_rocket, total_annual_cost`

定义：
[
\text{MassShare}_E=\frac{X_E}{X_E+X_R},\quad \text{CostShare}_E=\frac{C_E}{C_E+C_R}
]
（火箭同理）

输出文件建议：

* `outputs/q3/step4/fig_step4_asymmetry_dualaxis.png`

---

### 加分图 3：Step4 自身的“波动范围”（Boxplot / Errorbar）

你已经有 `results_xE/results_xR` 的 100 次样本。
建议额外在循环后构造每次成本样本（不改核心逻辑，只加 10 行）：

* `cost_i_elevator = xE_i*(c_E_per_ton + apex_cost_per_ton)`
* `cost_i_rocket = ((xR_i/q_payload)/s_R) * C_L_launch`
* `cost_i_total = cost_i_elevator + cost_i_rocket`

然后画：

* `fig_step4_cost_boxplot.png`（或直方图）
  论文一句话就能用：

> “在 severe preset 下，即使考虑供给分配随机波动，成本倒挂结构仍稳定存在（见箱线图）。”
